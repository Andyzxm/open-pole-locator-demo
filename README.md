# Open Pole Locator map (view-only)

Utility poles located by Open Pole Locator in the processed areas (Knoxville, Seattle, Apex, Newton, Portland area), with Mapillary's own pole detections and public utility pole records for comparison.

Street-level photos, derived pole points and Mapillary detections: (c) Mapillary contributors, CC BY-SA 4.0. Utility records: Seattle City Light, Town of Apex and City of Newton public data. Base maps: (c) OpenStreetMap contributors, OpenFreeMap. Page code: Apache 2.0.
